# v1.0.0

First public release for Windows 11. Download the portable DaybetterLEDStrip-1.0.0.exe and follow the README to sync Apple Music album artwork with a Daybetter P065.

Includes RGB preview and manual controls, per-album colors, optional timed lyrics, tray controls, system volume, and English, simplified Chinese, and traditional Chinese.

Known behavior: P065 firmware 1.2.4 showed stepped color changes in both the official phone app and direct Bluetooth testing. Similar requested colors may look the same, and some songs show little visible change. See the README for examples and workarounds.
