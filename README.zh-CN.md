# Daybetter LED Strip · 音乐联动控制器

[English README](README.md)

这是一款 Windows 便携工具。它读取 Apple Music 桌面客户端正在播放的专辑封面，通过蓝牙把目标灯色发给 Daybetter P065。

## 能做什么

- 每首歌对应一个固定灯色。暂停、退出 Apple Music 或停止联动时，灯带保留当前状态。
- 从封面取主色。黑色占多数时尝试明显的对比色，封面几乎全黑时熄灯。
- 预览取色、手动色轮、Hex 设色、开关和亮度指令，以及保存每张专辑的自定义灯色。
- 可选歌词查询、按句同步及有时间戳时逐词高亮。提供旋转封面背景、最大化歌词区、系统托盘、系统音量和静音。
- 支持英语、简体中文和繁體中文。

## 怎么用

1. 在 [Releases](https://github.com/leoooolol27/daybetter-led-strip-music-sync/releases) 下载 v1.0.0 的 `DaybetterLEDStrip-1.0.0.exe`。在 64 位 Windows 11 上直接运行。
2. 打开电脑蓝牙，给一台 P065 通电。如果手机 App 正在控制灯带，先从手机端断开。
3. 在同一个 Windows 会话中用 Apple Music **桌面客户端**播放歌曲，然后点击 **开启灯带联动**。想先看目标颜色，可以用 **只预览封面**。预览不会向灯带发送指令。
4. 将鼠标停到色号上查看色样。打开 **原始 RGB** 可以对比增强前后的目标灯色。某张专辑偏色时，可以输入你更喜欢的 Hex 值，再点 **保存专辑灯色**。
5. 单独试灯时，先停止联动或预览，再输入色号并点 **设置灯色**。点击 **歌词** 会启用联网查询。最大化后可以看到更多后续歌词。
6. 关闭或最小化后，可从系统托盘重新打开、关闭联动或退出。锁屏联动要求电脑保持唤醒。系统音量会影响当前默认输出设备上的其他应用。

## 为什么有些歌变化不明显？

开发主要基于 **P065，固件 1.2.4**。实测时，即使用官方手机 App 拖动色轮，这台灯带也会**一格一格地变化**。Windows 直接发送 RGB 同样会遇到色差。比如相近的橙色在灯带上可能几乎一样，或都显得偏黄。这个现象指向测试设备的显色限制，具体是控制器还是灯珠、究竟有多少可见色阶，目前没有测量确认。

软件显示的是**请求发送的 RGB**。实际灯色还取决于灯带和房间环境。两首歌的封面主色接近、封面取出的颜色偏暗或饱和度低，或者两个 RGB 值落在灯带可见的同一档时，切歌效果就可能不明显。同一张专辑也经常有意沿用相同灯色。界面旋转动画的流畅程度不会改变灯带的显色色阶。

可以切换 **原始 RGB**、手动试几组相近色号，或者为专辑保存效果更明显的颜色。开关和亮度的物理响应取决于设备和固件。其他 Daybetter 型号尚需验证。

## 数据与反馈

歌曲和播放时间轴来自 Apple Music 客户端。只有主动开启歌词查询后，应用才会把歌名、艺人及可用的专辑名和曲长发给 LRCLIB。歌词覆盖率和准确度会随录音版本变化。语言和专辑灯色保存在本机。

在 **反馈** 面板复制 Bug 模板后，到 [GitHub Issues](https://github.com/leoooolol27/daybetter-led-strip-music-sync/issues/new/choose) 提交。请写明 Windows 版本、灯带型号、固件和复现步骤。色差报告也欢迎附上目标 Hex 值。
